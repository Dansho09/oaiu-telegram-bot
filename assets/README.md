# Изображения проекта

- `banner.png` — обложка README в цветах OAIU.
- `demo.png` — иллюстрация диалога с демонстрационным текстом, без реальной переписки.
- `oaiu-avatar.png` — подготовленный аватар бота на основе выбранного пользователем логотипа OAIU с [сайта университета](https://caiu.edu.kz/). Обработан с помощью ImageGen.
- SVG-файлы — редактируемые источники обложки и демонстрации.

Личные данные и токены в изображения не включены.
