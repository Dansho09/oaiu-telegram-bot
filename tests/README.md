# Проверки бота

Для рабочей Cloudflare-версии нужны Node.js 24 и pnpm 11.25.0:

```bash
cd cloudflare
pnpm install --frozen-lockfile --ignore-scripts
pnpm test
```

Проверяются диалог, история и очередь, точный тайминг и конструктор программы, разделение пользователей, права владельца, импорт DOCX с предварительным просмотром, Word/PDF и казахские символы, раздельное оформление строк плана и заголовков Word, отдельные листы только для структурированного сценария и проверка пропусков. Проверяется казахский служебный интерфейс независимо от языка материала, казахский язык новых запросов по умолчанию и сохранение ограниченного контекста уточнений события. Зависимости фиксируются в `cloudflare/pnpm-lock.yaml`.

Для альтернативного Python-варианта запускайте из корня проекта:

```bash
python3 -m unittest discover -s tests -v
```

Обе группы тестов используют подставные ответы Telegram и Groq. Настоящие токены и сетевые запросы не нужны. GitHub Actions запускает Node.js 24 и Python 3.11–3.14.
